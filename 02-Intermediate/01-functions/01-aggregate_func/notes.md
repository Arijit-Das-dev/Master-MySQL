## Aggregate functions

| Functions      | What they do ?                        |
| -------------- | ------------------------------------- |
| **COUNT()**    | `Counts each values`                  |
| **SUM()**      | `Adds numeric values`                 |
| **AVG()**      | `Gives average value`                 |
| **MIN()**      | `Gives minimum numeric value`         |
| **MAX()**      | `Gives maximum numeric value`         |
