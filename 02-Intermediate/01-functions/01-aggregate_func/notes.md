## Aggregate functions
- We specifically use aggregate functions for statistical measurements or analysis.
- We always use ***GROUP BY*** clause with aggregate functions.


### List of aggregate functions.
| Functions      | What they do ?                        |
| -------------- | ------------------------------------- |
| **COUNT()**    | `Counts each values`                  |
| **SUM()**      | `Adds numeric values`                 |
| **AVG()**      | `Gives average value`                 |
| **MIN()**      | `Gives minimum numeric value`         |
| **MAX()**      | `Gives maximum numeric value`         |
