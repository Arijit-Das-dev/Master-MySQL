## DROP TABLE - To delete the existing table
- We use DROP statement to delete the entire table.

### SYNTAX :
```sql
-- SQL COMMANDS

DROP TABLE table_name;
```

### QUERIES :
```sql
-- SQL COMMANDS

-- DROP users table
DROP TABLE users;

-- DROP employees table
DROP TABLE employees;

-- DROP table customers
DROP TABLE customers;

-- DROP table students
DROP TABLE students;

-- DROP table sales
DROP TABLE sales;
```
